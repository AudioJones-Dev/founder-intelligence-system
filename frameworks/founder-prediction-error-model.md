# Founder Prediction Error Model

## Purpose
Detect and correct gaps between founder expectations and observed outcomes.

## Problem It Solves
Unmeasured prediction error causes repeated strategic misses, delayed learning, and unstable execution confidence.

## Core Components
- Explicit prediction capture
- Outcome tracking window
- Error magnitude scoring
- Error cause decomposition
- Learning loop protocol

## Related Skills
- decision-compression
- moat-detection
- ghost-note-detection

## Operating Logic
1. Record forward-looking founder predictions with confidence levels.
2. Measure real outcomes at predefined checkpoints.
3. Calculate prediction error and classify error type.
4. Diagnose whether error source was signal quality, interpretation, or execution.
5. Encode corrected assumptions into doctrine or frameworks.

## Inputs
- Founder forecasts
- Outcome metrics
- Decision records
- Postmortem evidence

## Outputs
- Prediction error ledger
- Error taxonomy by domain
- Updated strategic assumptions

## Failure Modes
- Retrospective rewriting of original predictions
- Treating luck as validated model quality
- Ignoring nonlinear lag effects in outcomes

## Strategic Value
Builds institutional learning velocity by making strategic miscalibration explicit and correctable.

## Example Applications
- Quarterly forecast review
- GTM hypothesis evaluation
- Resource allocation recalibration

## Compression Summary
Turn prediction misses into explicit learning assets that improve future strategic judgment.
