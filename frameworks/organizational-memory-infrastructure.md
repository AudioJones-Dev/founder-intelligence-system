# Organizational Memory Infrastructure

## Core Definition
The systems, artifacts, and routines that allow a company to remember what it has learned — so that judgment, taste, and context survive turnover, growth, and time.

## Core Question
What does this business know that only one person can access?

## Diagnostic Signals
- onboarding is verbal and unrepeatable
- decisions get re-litigated every quarter
- post-mortems never re-enter the system
- new hires depend on Slack archaeology
- the same "lesson" is learned across multiple projects
- AI is used to generate, but never to remember

## Diagnostic Questions
- Where is the company's judgment stored?
- If three senior people left tomorrow, what would be lost?
- What decisions are made by re-deriving context that already existed?
- What "we already learned this" moments recur?
- How does the company convert experience into durable assets?

## Opportunity Pattern
In the AI era, the businesses with structured organizational memory compound. Those without it leak knowledge faster than they generate it. Memory infrastructure is becoming a primary moat.

## Use This Framework To Evaluate
- agencies and consultancies
- expert-led businesses
- AI-augmented teams
- acquisition targets where the IP is implicit
- internal tooling investments

## Scoring Logic
| Score | Meaning |
|---|---|
| 1 | Strong, queryable institutional memory |
| 3 | Documentation exists, lightly used |
| 5 | Partial memory; key gaps |
| 7 | Memory lives in people, not systems |
| 10 | The business forgets faster than it learns |

## Scoring Dimensions
- **Externalization** — % of judgment captured outside individuals
- **Retrievability** — can the right context be surfaced at the moment of decision
- **Compounding** — does each project make the next one cheaper / better
- **Survivability** — does the knowledge survive turnover

## Strategic Output
If score is 7+, organizational memory infrastructure is both a risk to mitigate and an opportunity to build into a moat. In service businesses, this is often the *real* asset being undervalued.

## Common Failure Modes
- Mistaking a documentation site for memory infrastructure
- Capturing artifacts without capturing the *decisions* behind them
- Letting AI generate new content without feeding the memory layer
