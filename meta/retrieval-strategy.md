# Retrieval Strategy

## Retrieval goals

- High precision: return the most semantically relevant assets.
- High interpretability: preserve why an asset was retrieved.
- Low ambiguity: use ontology terms and schema fields as anchors.

## Retrieval hierarchy

1. Match doctrine context.
2. Match framework problem type.
3. Match skill detection logic and output contract.
4. Expand with ontology-linked neighboring nodes.

## Authoring rules for retrieval quality

- Keep section headers stable and template-aligned.
- Use explicit relation references (related skills, ontology refs).
- Write compression summaries as dense retrieval anchors.
