# Taxonomy

## Layer taxonomy

- **L0 Doctrine**: strategic and epistemic constraints.
- **L1 Frameworks**: systemized reasoning patterns.
- **L2 Skills**: atomic cognitive operations.
- **L3 Artifacts**: transcripts, extractions, research, examples.
- **L4 Execution**: agents and prompts.

## Naming taxonomy

- Use kebab-case file names.
- Use explicit nouns over abstractions.
- Maintain one semantic unit per file.
