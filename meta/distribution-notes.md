## Brand Language Bank (Distribution Layer)

The lines below are public-facing copy assets. They are *derived from* canonical doctrine but should not be cited from canonical files. Doctrine should be precise and falsifiable; slogans can be sharp and one-sided.

### Signature Lines
- You do not have an AI problem. You have a signal problem.
- You do not have a growth problem. You have a signal problem.
- More tools do not create more intelligence.
- Automation amplifies dysfunction.
- Analytics tells you what happened. Attribution tells you why.
- Signal is anything that improves the next decision.
- Noise is anything that consumes attention without changing action.
- Intelligence is not the tool. Intelligence is the system.
- The founder is not the bottleneck because they lack effort. They are the bottleneck because the system routes too many decisions through them.
- The goal is not more data. The goal is better judgment.

### Brand Tone
- Precise
- Direct
- Intellectually sharp
- Founder-accessible
- Skeptical of hype
- Systems-oriented
- High-signal
- Casual when useful
- Scientific without sounding academic

## Framework Usage Rules (Distribution Layer)

These are *messaging* rules — when to lead with which framework in public-facing copy or sales conversations. They are NOT routing logic for the agent layer (that lives in `meta/routing.md`).

| Use M.A.P. when talking about | Attribution / marketing ROI / lead source clarity / causal tracking / revenue intelligence / campaign performance / data-driven decisions |
| Use N.I.C.H.E. when talking about | Positioning / market selection / offer design / category creation / founder differentiation / local or service-business opportunity / productized consulting |
| Use Applied Intelligence Systems when talking about | AI strategy / business systems / founder operating systems / AI implementation / workflow automation / intelligence layers / human + AI decision-making |
| Use Signal Audit when talking about | Diagnostics / noise reduction / business clarity / operational bottlenecks / dashboard simplification / strategy before tactics |
| Use Founder Prediction Error when talking about | Founder confusion / growth plateaus / misattribution / cognitive overload / reactive decision-making / strategic clarity |
