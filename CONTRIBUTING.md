# Contributing to Founder Intelligence System

## Purpose of contribution

Contributions should improve semantic quality, retrieval quality, and composability of the intelligence architecture.

## Contribution rules

1. Use existing templates in `templates/`.
2. Preserve required heading order.
3. Keep language concrete and operational.
4. Use ontology-aligned terminology.
5. Add or update schemas only when structure changes are necessary.
6. Avoid redundant files that duplicate existing semantics.

## Quality standards

Before submitting:

- confirm headings and field naming are consistent,
- confirm outputs are useful for both human operators and AI agents,
- confirm relationships between skills, frameworks, doctrine, and ontology are explicit.

## Scope discipline

Do not add application infrastructure, orchestration frameworks, cloud dependencies, or unrelated tooling. This repository is the canonical intelligence layer.
