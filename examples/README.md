# Examples

Worked examples that show the system in action — fully filled-in briefs, multi-framework analyses, real moat detections, calibration cycles.

## What Belongs Here

- Filled-in opportunity briefs (per `templates/opportunity-brief-template.md`)
- Market thesis exercises (per `templates/market-thesis-template.md`)
- End-to-end pipelines: transcript → extraction → routing → framework application → composite scoring → brief
- Calibration cycles showing Founder Prediction Error Model applied over time

## What Does Not Belong Here

- Real customer or founder names without explicit authorization
- Material that contains secrets, financials, or personally identifying information
- Drafts of templates themselves (those belong in `templates/`)

## Naming Convention

`[YYYY-MM-DD]-[case-slug]-[type].md`

Examples:
- `2026-01-12-acme-corp-opportunity-brief.md`
- `2026-02-04-saas-category-market-thesis.md`

## Status

This layer is intentionally empty in v0.1. Examples will be added as the pipeline produces shareable results.
